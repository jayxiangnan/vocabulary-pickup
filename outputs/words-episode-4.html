1
tackle
/ˈtækl/
v. 处理，应对，着手解决
We need to tackle this problem before it escalates.
我们需要在问题升级之前着手解决它。
💡tack（钉子）+ le = 像钉子一样扎进去 = 着手处理。联想橄榄球中 tackle = 扑倒对方球员，引申为正面迎战难题。常用搭配 tackle a problem/challenge。
2
ambiguous
/æmˈbɪɡjuəs/
adj. 含糊的，模棱两可的
The manager's instructions were ambiguous, so nobody knew what to do.
经理的指示含糊不清，所以没人知道该做什么。
💡ambi（两边）+ gu（走）+ ous = 两边走 = 模棱两可。前缀 ambi- = both，如 ambidextrous（左右手都灵活的）。反义词 unambiguous（明确的）。
3
amend
/əˈmend/
v. 修改，修正，改正
We need to amend the contract to reflect the new terms.
我们需要修改合同以反映新的条款。
💡a（向）+ mend（修补）= 修好 = 修正。与 mend（修补）同源，a- 加强语气。法律文件高频词：amend a contract/law/agreement = 修改合同/法律/协议。
4
diligent
/ˈdɪlɪdʒənt/
adj. 勤勉的，认真刻苦的
He is a diligent worker who never misses a deadline.
他是个勤勉的员工，从不错过截止日期。
💡di（分开）+ lig（选）+ ent = 仔细分辨挑选 = 认真的。词根 lig/leg = choose，同根词 intelligent（聪明 = 善于分辨选择）。名词 diligence，商务术语 due diligence = 尽职调查。
5
prevalent
/ˈprevələnt/
adj. 普遍的，盛行的，常见的
This view is prevalent among young professionals.
这种观点在年轻职场人士中很普遍。
💡pre（在前面）+ val（力量）+ ent = 力量占优势的 = 盛行的。词根 val = strong，如 prevail（盛行）、valid（有效的 = 有力量的）。形容广泛存在的现象或态度。
